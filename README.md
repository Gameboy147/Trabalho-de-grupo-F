# Trabalho Prático 2 - Gestão de Quartos

Aplicação em Python para consola de texto desenvolvida no âmbito da UC Ambientes de Desenvolvimento Colaborativo[cite: 2, 3].

## Módulo de Quartos (`quartos.py`)[cite: 32]
- **Inventário e detalhes:** visualização de quartos, tipo, cama e estado[cite: 1].
- **Operações CRUD:** criar, listar, atualizar estado e remover quartos na consola[cite: 1, 3].
- **Histórico:** registo e consulta de hóspedes associados aos quartos[cite: 1].
